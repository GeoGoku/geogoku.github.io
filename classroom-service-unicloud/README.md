## 上课操作

1. 老师选择课程、填写班级，新建本次课堂；学生扫码，填姓名、学号进入。只有一个进行中的课堂时直接加入，否则选择班级。
2. 讲到题目时，老师点击“开始本题作答”。学生在对应题号选 A/B/C/D 并提交，显示“已提交”才代表保存成功。
3. 老师选正确答案，点击“收题并公布答案”，一次获得选项人数并公布答案。也可以只收题或手动刷新统计。
4. 手机不自动刷新。答案优先看老师投屏；需要查看个人结果时点“同步讲次 / 结果”。切换讲次后，全班点一次同步。
5. 下课点击“结束本次课堂”，导出成绩汇总表或逐题明细。下次新建课堂，二维码仍然相同。

学生端每讲预列 20 道题。未开放的题、已截止的题、已结束的课堂都由服务器拒收；成功提交后的答案不能更改，重复提交只返回第一次保存结果。原浏览器保存身份，换手机或换浏览器不能冒用已加入的同一学号。

## 免费额度估算

按每堂 35 人、15 道题、两个班合计每周 5 堂计算：

| 操作 | 每堂请求数 |
| --- | ---: |
| 学生加入 | 约 35 |
| 逐题提交 | 525 |
| 老师开题、收题并公布答案 | 30 |
| 登录、课堂列表、新建、结束、导出 | 约 5 |
| 合计（没有额外同步、刷新或重试） | 约 595 |

20 堂约 11,900 次；23 堂约 13,685 次；25 堂约 14,875 次。全班每同步一次多 35 次。有多个未结束课堂时，进入也可能多一次查找。不能保证所有月份都在 15,000 次内；测试、重试和手动刷新也计入实际使用。不要每题让全班刷新结果。删除旧答案不会返还已经消耗的调用次数。

页面空闲时不请求云端，倒计时在本地显示。提交只发一个请求，无自动重试；老师开题/收题返回最新统计，不额外读取一遍。答案保存格式压缩，函数配置内存为 256 MB。

支付宝云免费版还限制运行资源（1000 GBs）、出网流量、数据库读写量等；实际以控制台当期用量为准。免费空间须主动续期，通常到期前 15 天可续。保持免费套餐，不充值、不升级、不打开超限按量。官方规则：https://doc.dcloud.net.cn/uniCloud/price.html#支付宝云

## 部署与数据

- 静态页面：本仓库 classroom/。
- 后端：classroom-service-unicloud/ 下的 uniCloud-alipay 云函数与 schema；通过 HBuilderX 关联自己的支付宝云空间后上传。
- 函数私有文件 private-config.json 需要包含 teacherSecret（高强度老师口令）。只放在本地部署目录，绝不能提交公开仓库。部署前从示例文件复制并自行设置口令。
- 数据集合 classroom_sessions 禁止客户端直读写；教师认证和学生身份校验在云函数处理。教师口令、学生身份令牌不放在网址中。
- 跨域请求使用 text/plain 封装 JSON，避免平台默认 URL 的 OPTIONS 限制。教师/学生敏感接口返回 Cache-Control: no-store。
- 临时迁移入口已关闭。旧 Cloudflare 数据保留，6 个课堂、13 条学生记录、10 道题、6 条答案已迁移并核对数量。
- 8 项规则测试、35 人并发交卷、手机尺寸浏览器交卷/公布/换讲/超时拒收/CSV 导出已验证通过。真实手机网络连通性以用户手机最终测试为准。

当前使用平台默认测试域名，其可用性受平台限制，不等于付费服务保障。
